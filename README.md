# Потихоньку

Мягкий помощник против прокрастинации: без стыда → крошечный шаг → план «если — то» → короткий таймер.

Опирается на подходы с исследовательской поддержкой:

- **самосострадание** вместо самокритики (критика усиливает откладывание)
- **маркировка чувства** (прокрастинация часто регулирует эмоции)
- **MCII**: желание → желаемый итог → препятствие → план «если — то»
- **правило ~2 минут / крошечный старт** — снизить порог начала
- **короткий таймбокс** — внешняя рамка без давления «доделать всё»

**Ссылка:** https://akarnauhov.github.io/potikhonku/
