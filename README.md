# Потихоньку

Из залипания к старту: **разные маршруты под причину**, почти без ввода текста, лёгкая геймификация.

## Как устроено

1. Выбираешь, что мешает (тревога / усталость / скука / страх / перегруз / «просто»)
2. Идёшь по **своему** короткому пути — только тапы
3. Таймер + очки ✦, серия дней 🔥, уровни и значки

Опора на исследования: самосострадание вместо стыда, маркировка аффекта, план «если — то», крошечный старт.
